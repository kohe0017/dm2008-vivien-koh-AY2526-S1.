The mini project is a reimagined flappy bird game called flappy meow, with a cat head that meows every time the space key is pressed. 
Reflection: I felt like the base guiding code was mostly comprehensive to allow us to make changes to make the game a functioning flappy bird, what was really difficult was making the game then unique, creative and interesting. When I tried implementing new changes, I was met with errors and confusion when I realised not everything was as straightforward as I had thought. That resulted in me having to tone down my expectations for how my game was going to look like. That realisation that my creativity was hampered by my coding abilities was quite a wake-up call to reconcile with, and I hope moving forward I can continue to improve my own coding abilities without a huge reliance on AI.  I really wanted to do this game entirely by scratch because my previous experience with coding gave me completely no tutorials or lessons, with only AI to help me. Because of that, I had no foundations and learnt no code from all those projects I spent so much time on.
